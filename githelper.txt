1. Check Existing SSH Keys 
sh
 
 
 
1
ls -al ~/.ssh
 
 

Look for files named id_rsa.pub, id_ed25519.pub, or similar. 
2. (If Needed) Generate a New SSH Key 

If you don't have a key or want to create a fresh one: 
sh
 
 
 
1
ssh-keygen -t ed25519 -C "your_email@example.com"
 
 

    Press Enter to accept the default location.
    Optionally, set a passphrase.
     

3. Add the SSH Key to the SSH Agent 
sh
 
 
 
1
2
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519
 
 

(Change the filename if your key is named differently.) 
4. Copy Your Public Key 
sh
 
 
 
1
cat ~/.ssh/id_ed25519.pub
 
 

Copy the whole output. 
5. Add the SSH Key to GitHub 

    Go to GitHub SSH keys settings page .
    Paste your copied public key and save.
     

6. Test the SSH Connection 
sh
 
 
 
1
ssh -T git@github.com
 
 

You should see a welcome message if everything is set up correctly. 
7. Try to Push Again 
sh
 
 
 
1
git push
 
 

If your repo is using HTTPS instead of SSH:
You can change the remote URL to HTTPS, which uses your GitHub username/password (or token): 
sh
 
 
 
1
git remote set-url origin https://github.com/username/repo.git
